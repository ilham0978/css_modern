Tentang Project Kami

Website ini dibuat sebagai tugas kelompok mata kuliah Pemrograman Web, dengan tujuan menerapkan HTML, CSS Modern, CSS Animation, dan Bootstrap dalam satu project nyata yang bisa dipresentasikan.

Setiap anggota tim berkontribusi pada bagian yang berbeda — mulai dari desain tampilan, penulisan kode, hingga penyusunan materi presentasi.

Teknologi yang Digunakan
HTML5 CSS3 Bootstrap 5 JavaScript AOS.js npm

Sebelum vs Sesudah CSS Modern

Elemen yang sama, dengan dan tanpa CSS Styling Modern

Tanpa CSS Modern

Kartu polos: tanpa border-radius, tanpa box-shadow, tanpa transition. Tampilan mengikuti gaya bawaan browser.

Dengan CSS Modern

Kartu dengan border-radius, box-shadow, gradient, dan transition halus saat di-hover.

Istilah CSS Modern & Animation

Ringkasan cepat istilah yang dipakai di project ini

klik untuk salin
transition

Membuat perubahan properti (warna, ukuran, posisi) terjadi halus, bukan tiba-tiba.

klik untuk salin
transform

Menggeser, memutar, atau membesarkan elemen tanpa mengubah tata letak lain.

klik untuk salin
@keyframes

Mendefinisikan tahapan animasi dari awal sampai akhir secara berurutan.

klik untuk salin
Flexbox

Menyusun elemen sejajar/tengah secara otomatis dalam satu baris atau kolom.

klik untuk salin
CSS Grid

Mengatur layout dalam baris & kolom yang menyesuaikan otomatis ke lebar layar.

klik untuk salin
CSS Variables

Menyimpan nilai (warna/ukuran) sekali, dipakai berkali-kali lewat var().

klik untuk salin
backdrop-filter

Efek blur tembus pandang di belakang elemen (glassmorphism).

klik untuk salin
box-shadow

Memberi efek bayangan supaya elemen terlihat mengambang.

Pertanyaan Umum

Kumpulan teknik CSS terbaru seperti CSS Variables, Flexbox, CSS Grid, border-radius, box-shadow, transition, dan responsive design yang membuat tampilan website lebih rapi dan fleksibel tanpa menambah banyak kode.

CSS Modern adalah teknik tata letak & styling, sedangkan CSS Animation khusus untuk pergerakan elemen memakai @keyframes — contohnya avatar yang berputar dan teks yang menyala pada halaman ini.

Bootstrap mempercepat pembuatan komponen standar (navbar, grid, form, accordion ini sendiri), sementara CSS custom dipakai untuk sentuhan unik dan animasi yang tidak disediakan Bootstrap.

AOS (Animate On Scroll) membuat elemen otomatis muncul dengan animasi begitu terlihat di layar saat halaman di-scroll, tanpa perlu menulis @keyframes manual untuk tiap elemen.

Secara cara instalasi memang sama — keduanya didaftarkan sebagai dependencies di package.json dan diunduh lewat npm install. Namun secara fungsi berbeda kategori: Bootstrap adalah CSS framework yang menyediakan kelas siap pakai untuk styling dan layout (seperti pada project ini), sedangkan React adalah library JavaScript untuk membangun antarmuka berbasis komponen, di mana HTML dihasilkan secara dinamis oleh kode JS. Project ini sendiri hanya memakai Bootstrap dan JavaScript biasa (vanilla JS), belum menggunakan React.

CSS kuno mengatur layout pakai float yang ribet dan tidak ada animasi. CSS modern pakai Flexbox/Grid untuk layout yang lebih rapi, CSS Variables untuk warna yang gampang diubah, serta transition dan @keyframes untuk animasi halus — semuanya sudah dipakai di halaman ini.

npm install mengunduh library ke folder node_modules di komputer, cocok untuk project yang pakai build tool (bisa dikelola versinya lewat package.json, tapi butuh proses bundling). CDN cukup menempel tag <script>/<link> ke file yang di-hosting online, tanpa install apa pun — lebih simpel untuk project HTML biasa seperti ini, tapi butuh koneksi internet agar library-nya termuat.
